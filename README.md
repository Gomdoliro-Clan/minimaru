# 미니 마루

부산소프트웨어마이스터고등학교 입학전형 시스템 **마루**를 축소한 과제용 프로젝트입니다.

## 상황

여러분은 오늘부터 미니 마루의 프론트엔드 유지보수 담당자입니다.
이전 담당자는 졸업했고, 코드는 동작은 하지만 **운영 중 학생·학부모 문의가 계속 들어오고 있습니다.**
문제를 찾아 원인을 밝히고 고쳐주세요.

## 실행 방법

```bash
pnpm install
pnpm dev
```

http://localhost:3000 에 접속합니다. 별도의 백엔드는 필요 없습니다.

- API는 [MSW](https://mswjs.io)로 브라우저 안에서 동작하는 mock 서버(`src/mocks/`)가 응답합니다.
- 데이터는 브라우저의 localStorage에 저장됩니다.
- 회원가입 인증번호는 항상 `123456`입니다.

## 개발용 패널

화면 오른쪽 아래의 🕒 버튼을 누르면 개발용 패널이 열립니다.

- **시간 조작**: 원서 접수 전, 접수 중, 마감 후, 발표 후 등 원하는 시각으로 이동할 수 있습니다. 직접 날짜와 시각을 입력할 수도 있습니다.
- **데이터 초기화**: mock 서버의 회원, 원서 데이터와 로그인 정보를 모두 지웁니다.

## 규칙

- `src/mocks/`는 **백엔드 팀이 만든 서버**라고 생각하세요. 수정하지 않습니다. API 명세는 [docs/api.md](docs/api.md)에 있습니다.
- `public/mockServiceWorker.js`도 수정하지 않습니다.
- 그 외의 코드는 자유롭게 수정할 수 있습니다.

## 폴더 구조

```
src/
├── app/          # 페이지 (Next.js App Router)
├── apis/         # axios 인스턴스
├── components/   # 컴포넌트
├── constants/    # 상수
├── hooks/        # 커스텀 훅
├── mocks/        # mock 서버 (수정 금지)
├── schemas/      # zod 스키마
├── services/     # API 호출, React Query 훅
├── stores/       # jotai atom
├── styles/       # 디자인 토큰
├── types/        # 타입
└── utils/        # 유틸 함수
```

## 성적 환산 규칙

총점 150점 = 교과 120점 + 출결 15점 + 봉사 15점

- **교과 (120점)**: 2-1, 2-2, 3-1 세 학기. 과목은 국어, 영어, 수학, 사회, 과학. 성취도 A=5, B=4, C=3, D=2, E=1. 이수하지 않은 과목(`-`)은 평균에서 제외합니다.
  - 학기별 평균을 구하고, 2-1 : 2-2 : 3-1 = 3 : 3 : 4 가중치로 가중 평균을 냅니다.
  - 교과 점수 = 가중 평균 ÷ 5 × 120. **최종 점수에서만** 소수점 셋째 자리에서 반올림합니다.
  - 자유학기 등으로 한 학기 전체가 비어 있으면, 나머지 학기의 가중치만으로 계산합니다.
- **출결 (15점)**: 결석 1회당 3점 감점. 지각, 조퇴, 결과는 합쳐서 3회를 결석 1회로 환산합니다. 최저 0점입니다.
- **봉사 (15점)**: 15시간 이상 15점, 7~14시간 10점, 6시간 이하 5점입니다.
- **검정고시**: 과목별 점수(0~100)의 평균 ÷ 100 × 120. 출결과 봉사는 만점입니다.
